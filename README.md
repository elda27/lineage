# Lineage
[EN](./README.md)/[JP](./README.jp.md)

This is a desktop application for recording daily observations and the connections between those observations and the results they produce.

> [!WARNING]
> This is currently an early development version. It is primarily implemented for local use on Windows, and specifications and data structures may change.


## Concept

Our project makes it easy to take notes while you work. The editor opens instantly with a keyboard shortcut. Notes are easy to search and edit because they can be easily tagged and retrieved whenever you need them.

If you take notes in a notepad, organizing them can become tedious. If you use tools such as OneNote, they can be too slow, so you may hesitate to write down something that seems unimportant at the time. However, that small note may later spark an important idea.

Our project solves this problem by making it easy to capture ideas that may inspire you later.

## Main Features

### Recording

- Open Quick Input from the application you are working in with `Alt + Space`
- Add metadata necessary for searching with `# tags`
- Complete tag suggestions based on past input frequency and abbreviations
- Add to past notes with `+ past note title`

### Reviewing and Organizing

- View a list of notes, search by title, body, and tags, and view details

- Fast search with comprehensive metadata.
