# Lineage
[EN](./README.md)/[JP](./README.jp.md)

日々の気づきと、そこから生まれた成果のつながりを残すためのデスクトップアプリです。

> [!WARNING]
> 現在は初期開発版です。Windows 向けのローカル利用を中心に実装しており、仕様やデータ構造は変更される可能性があります。

## コンセプト
このプロジェクトでは、作業中に手軽にメモを取ることができます。キーボードショートカットを使えば、エディターを即座に起動可能です。メモには簡単にタグを付けられ、必要な時にすぐ呼び出せるため、検索や編集もスムーズに行えます。

一般的なメモ帳を使っていると、メモの整理が煩雑になりがちです。一方、OneNoteのようなツールは動作が重いことがあり、その時点では重要ではないと思えることを書き留めるのをためらってしまうかもしれません。しかし、そうした些細なメモが、後になって重要なアイデアのきっかけになることもあります。

本プロジェクトは、将来のインスピレーションにつながるようなアイデアを気軽に記録できるようにすることで、こうした課題を解決します。

## 主な機能

### 記録する

- `Alt + Space` で、作業中のアプリからクイック入力を開く
- `#タグ`で検索に必要なメタ情報を追加
- 過去の入力頻度や短縮入力をもとにタグ候補を補完する
- `+過去のメモの見出し`で過去のメモに追記も用意

### 見返して整理する

- メモの一覧表示、タイトル・本文・タグの検索、詳細表示を行う
- 充実させたメタ情報で高速に検索
