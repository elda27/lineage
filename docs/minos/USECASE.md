minos ユースケース

本書は minos の第1弾ユースケースを定義する。
思想は docs/minos/CONCEPT.md、技術設計は docs/minos/DESIGN.md を参照。

各シナリオは結合テストの正である。
シナリオを変更したら対応するテスト(.claude/skills/usecase-tests 参照)も追随させること。

---

1. 対象ユースケース(第1弾)

todo / メモの雑登録。

業務中に「あとでやる」と決めたことを、作業を中断せずに数秒で登録し、
後から別アプリ(ビュワー)の一覧でチェックしてタスクを処理する。

一瞬で開く
↓
todo を登録
↓
(あとで)一覧からチェックして処理

---

2. 主シナリオ: 業務中の todo 登録

前提: minos は常駐している。todo テーブルは定義済み。

1. 利用者はコーディング / ブラウジング / ドキュメント作成などの作業中に
   「あとでやる」ことを思い付く
2. グローバルホットキーを押す
3. minos はこの瞬間に、直前のフォアグラウンドアプリを検出し、
   そのウィンドウのスクリーンショットを取得する(利用者の操作は不要)
4. minos のクイック入力ウィンドウが前面に表示される
   - テーブルは前回選択したものがデフォルト選択される
     (todo 連続登録なら選択操作は 0)
5. タイトル(何をやるか)を入力する
6. タグを確認する
   - 直前のフォアグラウンドアプリ名が自動でタグとして付与済み
   - 必要なら補完候補から追加のタグを付ける
7. Enter で登録。ウィンドウは即座に消え、フォーカスは元のアプリに戻る
8. 利用者は元の作業を続ける

ホットキー
↓
(自動: 直前アプリ検出 + スクショ)
↓
タイトル入力
↓
(自動: タグ付与) + 任意でタグ追加
↓
Enter → 登録完了・消える

目標時間: ホットキー押下から登録完了まで 5 秒以内。

---

3. 入力されるデータ

todo テーブルのスキーマ例:

| 列          | 型       | 入力元                              |
|-------------|----------|-------------------------------------|
| title       | text     | 手入力(必須)                      |
| status      | text     | 自動(初期値 "open")               |
| tags        | tag list | 自動(直前アプリ名)+ 手動(補完) |
| source_app  | text     | 自動(直前アプリのプロセス名)     |
| screenshot  | 添付     | 自動(直前ウィンドウの PNG)       |
| created_at  | datetime | 自動(登録時刻)                    |

タグの由来は2系統ある。

- 自動タグ: 直前にフォアグラウンドだったアプリから生成する
  (例: ブラウザで調べ物中なら "chrome"、コードレビュー中なら "vscode")
- 手動タグ: 利用者が追加する。過去に使ったタグを補完候補として提示する

手で打つのは title と任意の追加タグだけである。

---

4. 後続フロー(minos の責務外)

登録された todo は別アプリ(ビュワー)から閲覧する。

ビュワーで一覧表示
↓
todo を選んで処理
↓
チェック(status を done に更新)

- minos の責務は「登録まで」。一覧・チェック・編集はビュワーが行う
- minos とビュワーは同一の SQLite ファイルを共有する(DESIGN.md 7章)
- スクショと自動タグにより、後から見返した時に
  「どの作業中に発生した todo か」を思い出せる

---

5. 派生ユースケース

5.1 雑メモ

todo ではない気付き・断片的なメモも同じ操作で登録する。

- テーブル選択で "memo" を選ぶ(あるいはメモ用スキーマのテーブルを定義する)
- title(または本文)のみ必須。タグ・スクショの自動付与は todo と同じ

---

5.2 将来のテーブル例

スキーマ駆動(CONCEPT.md 3.3)なので、テーブル定義を追加するだけで
新しい記録が増やせる。minos 本体の変更は不要。

- 体重記録: weight(number)、measured_at(datetime)
- 支出記録: amount(number)、category(tag)、note(text)
- 読書メモ: book_title(text・補完)、quote(text)、thought(text)

いずれも「発生した瞬間に数秒で登録する」という利用形態は共通である。
